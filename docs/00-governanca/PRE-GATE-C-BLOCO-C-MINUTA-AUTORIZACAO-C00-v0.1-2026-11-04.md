## 5. Controles de qualidade e política de segurança

- Fazer apenas desenvolvimento com dados fictícios e contratos simulados; nunca copiar banco de produção, tokens de CRM/Portal, dados de alunos ou materiais privados reais.
- Prever branches/PRs de código para revisão, testes, scanners disponíveis dentro de custos aprovados, documentação de mudança e critérios para impedir exposição pública.
- A stack deve permanecer tecnicamente independente do CRM/Portal; contratos reais UNI-C01..UNI-C08 serão integrados em fase autorizada posterior.
- Agentes IA podem auxiliar implementações somente dentro do escopo, permissões, registros de alteração, limites de consumo e revisão humana aprovados; não têm autonomia para comprar, fazer deploy público ou homologar a si mesmos.
- Mudança de stack, ambiente, escopo, novo serviço ou custo recorrente: registrar solicitação, impacto, revisão e aprovação antes de executar.
- A conclusão de C-00 **não abre automaticamente Gate H** (piloto/homologação) nem Gate L (lançamento).
