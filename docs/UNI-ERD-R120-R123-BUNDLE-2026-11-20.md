# Imagine Universidade — R120–R123: pacote íntegro de revisão (DRAFT)

**HOLD_NO_GO.** Trabalho exclusivamente sobre 35 aulas sintéticas em rascunho; nenhum aceite editorial autenticado, grant, autorização de release ou acesso a clientes.

## Entregas

- **R120:** manifesto JSON canônico com SHA-256 dos bytes da fonte versionada, de cada relatório e contagem de bytes. Une os três formatos offline (JSON, Markdown e HTML) sem presumir que a integridade seja uma assinatura digital.
- **R121:** verificação local dos quatro arquivos fixos; recusa symlinks, arquivos não regulares, alterações de bytes, limite excessivo e conjuntos incompatíveis.
- **R122:** regressões negativas de substituição de fonte, falsa aprovação, manifesto manipulado, truncamento, arquivos extras, entrada inválida e symlink.
- **R123:** workflow read-only isolado na branch do DRAFT; checkout da SHA exata e verificação dos 13 gates antes de declarar conclusão técnica.

## Reproduzir no checkout da PR, sem VPS nem serviços externos

Use um diretório temporário vazio e execute:

    OUT="$(mktemp -d)"
    node scripts/build-editorial-review-priority.mjs --json > "$OUT/report.json"
    node scripts/build-editorial-review-priority.mjs --markdown > "$OUT/report.md"
    node scripts/render-editorial-priority-html.mjs > "$OUT/report.html"
    node scripts/editorial-review-bundle.mjs > "$OUT/manifest.json"
    node scripts/editorial-review-bundle.mjs "$OUT"
    node scripts/check-editorial-review-bundle.mjs

O verificador confia apenas no arquivo content/mvp-cursos-v1.json do checkout; não permite fonte de dados externa. A pasta usada para revisão contém apenas os relatórios e o manifesto, sem arquivos com dados pessoais reais. Os quatro arquivos são verificados contra bytes gerados na mesma versão, não apenas contra hashes declarados no próprio manifesto.

## Não são evidências de produção

Hashes não constituem assinatura de pessoa ou prova pedagógica. Nenhum campo de aprovação local ou manifesto cria autorização. Os 210 itens de revisão das 35 aulas continuam exigindo avaliação humana autenticada.
